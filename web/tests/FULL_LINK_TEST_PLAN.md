# 全链路测试计划

## 测试目标

创建详细的全链路测试套件，覆盖 PrerenderShield 应用的所有功能模块的完整操作流程，确保每个功能都能正常工作，并且各模块之间的集成也能正常运行。

## 测试范围

### 1. 认证模块
- 登录流程（成功/失败场景）
- 登出流程
- 权限验证（未登录访问、已登录访问）
- 会话管理

### 2. 站点管理模块
- 站点创建（静态站点、代理站点、重定向站点）
- 站点编辑
- 站点删除
- 站点列表管理
- 站点状态管理（启用/禁用）
- 静态资源管理（文件上传、下载、删除、解压）
- 站点配置管理（WAF配置、预渲染配置、推送配置）

### 3. 预渲染模块
- 渲染预热配置
- 手动渲染操作
- 缓存预热操作
- 缓存管理（查看状态、清理缓存）
- 预渲染状态监控
- 推送配置管理
- 爬虫头配置

### 4. 防火墙模块
- 规则管理（创建、编辑、删除、启用/禁用）
- 攻击拦截测试
- 地理位置访问控制
- IP黑白名单管理
- 频率限制配置
- 防火墙状态管理

### 5. 监控模块
- 系统指标监控
- 性能图表展示
- 错误率监控
- 请求统计
- 时间范围切换
- 实时数据展示
- 数据导出功能

### 6. 日志模块
- 日志查询
- 日志过滤（按级别、时间、关键词）
- 日志分页
- 日志导出
- 日志清理

### 7. 系统配置模块
- 基础设置
- 数据库配置
- 缓存配置
- 安全设置
- 服务管理（启动/停止/重启）
- 服务状态监控

### 8. 爬虫管理模块
- 爬虫配置
- 爬取任务管理（开始/停止）
- 爬取历史查看
- 爬取统计分析

### 9. 概览模块
- 系统概览
- 关键指标展示
- 最近事件查看
- 站点状态监控
- 性能概览
- 安全状态监控

### 10. WAF设置模块
- 通用配置
- 规则集管理
- 威胁防护
- 机器人防护
- 模块启用/禁用
- 安全统计

## 测试方法

### 1. 端到端测试
- 使用 Playwright 进行端到端测试
- 模拟真实用户操作流程
- 验证每个功能的完整操作流程

### 2. 集成测试
- 测试模块之间的集成
- 验证数据在模块间的传递
- 测试完整的业务流程

### 3. 边界测试
- 测试边界情况
- 测试错误处理
- 测试性能边界

### 4. 回归测试
- 确保修复不会引入新问题
- 确保现有功能不会被破坏

## 测试工具

- **Playwright**：用于端到端测试
- **TypeScript**：用于编写类型安全的测试代码
- **Ant Design**：用于UI组件测试
- **React Router**：用于路由测试

## 测试执行计划

1. **准备阶段**：创建测试计划，设置测试环境
2. **执行阶段**：按照测试计划执行测试
3. **分析阶段**：分析测试结果，识别问题
4. **修复阶段**：修复测试中发现的问题
5. **验证阶段**：验证修复是否成功

## 测试标准

- **通过率**：所有测试用例必须通过
- **覆盖率**：覆盖所有功能模块的完整操作流程
- **可靠性**：测试结果必须可靠，能够重复执行
- **可维护性**：测试代码必须易于维护和更新

- 测试覆盖率
- 发现的问题及修复情况
