# 竞品调研报告 2026

> 调研时间: 2026-06-10
> 范围: WAF 防火墙 + 预渲染引擎 市场

---

## 一、市场全景

### 1.1 预渲染市场

| 梯队 | 代表产品 | 定位 | 价格 |
|------|---------|------|------|
| Tier 1 | **Prerender.io** | 托管预渲染标杆 | $49-$349/月 |
| Tier 1 | **Ostr.io** | 企业级托管 | $99-$499/月 |
| Tier 2 | **SEO4Ajax** | 托管替代方案 | $29/月起 |
| Tier 2 | **HadoSEO** | DNS 级预渲染 | $19/月起 |
| Tier 3 | **Rendertron** | Google OSS (已归档) | 免费/自托管 |
| Tier 3 | **Rendora** | Go 轻量方案 | 免费/自托管 |
| Tier 3 | **EdgeComet** | 开源渲染 + 缓存 | 免费/自托管 |
| Tier 3 | **ReviJs** | SPA 预渲染 CLI | 免费/开源 |

### 1.2 WAF 市场

| 梯队 | 代表产品 | 定位 | 价格 |
|------|---------|------|------|
| 商业 | **Cloudflare WAF** | 云 WAF 领导者 | $20-$200/月 |
| 商业 | **AWS WAF** | 云原生 | $5+/月 + 按量 |
| 商业 | **Imperva** | 企业级 | 定制报价 |
| 开源 | **ModSecurity + CRS** | 开源标准 (20年) | 免费 |
| 开源 | **Coraza WAF** | Go 实现 ModSecurity | 免费 |
| 开源 | **SafeLine** | 语义分析 WAF | 免费/社区版 |
| 开源 | **BunkerWeb** | 全家桶 WAF | 免费/Pro版 |
| 开源 | **PRX-WAF** | Pingora + Rust | 免费 |

### 1.3 关键趋势

1. **AI 爬虫崛起**: GPTBot、ClaudeBot、PerplexityBot 等 AI 爬虫已成标配需求，传统预渲染方案未覆盖
2. **开源 WAF 换代**: ModSecurity 已停止维护，社区向 Coraza (Go) 迁移，SafeLine 表现最佳
3. **WAF + 渲染融合**: 目前市场上没有将 WAF 和预渲染整合为单一产品的方案 — 这正是 Prerender Shield 的定位空白
4. **自建 vs 购买成本线**: 10万 URL/月是分水岭，以下托管划算，以上自建更经济

## 二、竞品详析

### 2.1 Prerender.io

| 维度 | 说明 |
|------|------|
| **类型** | 托管预渲染服务 |
| **价格** | $49/月 (25K渲染) → $349/月 (500K渲染) |
| **部署** | 中间件安装 (Nginx / Node.js) |
| **优势** | 市场规模最大，文档完善，框架兼容性好 |
| **劣势** | 无 WAF 功能，WAF 白名单 IP 不稳定，触发 Google Ads 隐藏标志，无免费版 |

### 2.2 Ostr.io

| 维度 | 说明 |
|------|------|
| **类型** | 企业级托管预渲染 |
| **价格** | 按需定价 |
| **优势** | 独享 IP 范围 (可白名单)，DOM 一致性 SLA 99.9%+，支持 Shadow DOM v2，缓存预热 API |
| **劣势** | 价格高，无 WAF 功能 |

### 2.3 Rendertron

| 维度 | 说明 |
|------|------|
| **类型** | Google 开源 (已归档) |
| **价格** | 免费，需自托管 |
| **优势** | 开源可控，Chromium 渲染 |
| **劣势** | 已停止维护，无缓存/监控/管理 UI，高内存消耗(500MB+/实例) |

### 2.4 Rendora

| 维度 | 说明 |
|------|------|
| **类型** | Go 开源反向代理预渲染 |
| **价格** | 免费 |
| **优势** | Go 编写，轻量，资源消耗低 |
| **劣势** | 社区不活跃，功能有限，无 WAF，无管理界面 |

### 2.5 EdgeComet

| 维度 | 说明 |
|------|------|
| **类型** | Go 开源渲染引擎 |
| **价格** | 免费 |
| **优势** | Redis 缓存，Prometheus 监控，AI 爬虫支持，水平扩展 |
| **劣势** | 无 WAF，无管理 UI，社区较小，需要自行搭建 |

### 2.6 Cloudflare WAF

| 维度 | 说明 |
|------|------|
| **类型** | 商业云 WAF |
| **价格** | 免费版 → Pro $20/月 |
| **优势** | 部署简单(DNS)，全球 CDN，DDoS 防护，SSL |
| **劣势** | 无预渲染，免费版规则受限，必须使用 Cloudflare DNS |

### 2.7 Coraza WAF

| 维度 | 说明 |
|------|------|
| **类型** | Go 开源 WAF 引擎 |
| **价格** | 免费 |
| **优势** | Go 编写，兼容 ModSecurity SecLang + OWASP CRS v4，K8s 原生集成 |
| **劣势** | 仅引擎，无预渲染，无管理 UI，高误报率 (92.77%) |

### 2.8 SafeLine WAF

| 维度 | 说明 |
|------|------|
| **类型** | 开源 WAF 防火墙 |
| **价格** | 免费社区版 |
| **优势** | 检测率 74.09%，误报仅 8.19%，语义分析算法，准确率 99.44% |
| **劣势** | 仅防火墙，无预渲染，无开源版性能限制 |
