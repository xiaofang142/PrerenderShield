# PrerenderShield 全量全链路 UI 自动化测试用例

## 1. 测试环境准备

### 1.1 环境要求
- Node.js 18+
- npm 9+
- Chrome/Firefox 浏览器
- Playwright 或 Cypress 测试框架
- 本地开发环境运行 `go run main.go`

### 1.2 测试账号
